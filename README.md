# Google One Offer Runner 静态安全审查

审查日期：2026-11-13。对象：群聊转发的 GoogleOneOfferRunner v1.1.0 压缩包。

本仓库仅记录静态审查结果，不包含原插件、优惠令牌、安装包、支付信息或优惠资格绕过代码。与 Google 无关联，不保证原插件安全或优惠有效。

## 审查结论

不建议将该扩展加载到日常使用、绑定付款方式的浏览器环境中。代码会改写优惠及结账请求，并自动操作订阅、购买和取消续订。

### 1. 零元判断不能保证不扣费

位置：原包 bg.js，zeroCostGate。

判断仅要求弹窗文本包含 `0.00`、`免费` 或不区分大小写的 `free`，未严格核对应付金额、币种和续订条件。例如 `10.00` 也包含 `0.00`；页面同时出现免费试用与收费说明时也可能通过。通过判断后后台会要求结账脚本点击购买按钮。

### 2. 存在银行卡信息自动填充遗留逻辑

位置：原包 content/play.js，fillCard、handleCvcChallenge；popup/popup.js，saveCfg、readForm。

结账脚本会从本地配置读取卡号、有效期、CVC、持卡人和部分地址字段并自动填表。当前面板无银行卡录入入口，但配置保存采用合并方式，保留旧版本已有的 card 字段。README 也提及银行卡信息明文保存在扩展本地存储。

上述证据不能证明当前版本会保存用户手动输入的新卡，但“扩展完全不接触银行卡信息”的说法不准确。压缩包中未发现实际个人银行卡数据。

### 3. 自动点击与结果识别存在误判可能

位置：原包 content/play.js，clickBuy、checkoutLoop、cancelFlow。

购买候选按钮包含“继续”“确认”等通用文字；成功与取消结果也依赖页面文字。未运行验证其在当前页面上的准确性，不能把日志中的成功视作实际账户结果。

### 4. 权限及页面响应处理

manifest.json 声明 storage、tabs、scripting 权限，并声明 Google One、Google Play、Google Accounts 的站点访问范围。主要内容脚本注入 Google One 和 Google Play；声明 Google Accounts 权限不代表已经在登录页执行脚本。

页面钩子拦截网络请求，并读取相关响应片段，经页面事件和扩展消息传入本地日志。这意味着日志可能包含订阅相关数据，公开截图前应检查并遮盖。

在本次已查看代码中，未发现明确向陌生服务器外传数据的证据；Telegram 链接出现在署名和页面链接中。此结论不是完整恶意代码排除证明。
